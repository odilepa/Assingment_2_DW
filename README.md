# Assingment_2_DW

In this assignment, I decided to create a portfolio of my own, based on my existing curriculum.

## General Composition

Across the entire project, I used a few variations of the same green, assigning lighter tones for inside divisions, and darker tones for borders, buttons and covers.

## Base Description

As a start, it contains a base description of myself, and what I do, it also contains a photo of myself for reference.

## Curriculum Items

For this section I divided multiple parts of my current curriculum into segments of consise information spread across 2 columns in a grid side by side, and created a form of button, that when clicked showcases the information in that topic, these are in a diferent color to the backdrop to create some diference in what they are.

## Projects

In this section, I added a set of projects that I was responsible for, initially covered by a cover that is removed once the user hovers the mouse over the item, as if opening a small box, inside said box, there is the name of the project, a link to the repository (if it exists), and a brief description of the project, these boxes where also split into two columns for clearer vision.

## Scroller

To aid in the movement of the page for user without the use of the scroll wheel, having a reference to each part of the page, for easy access, this can be seen in the top right corner, where upon clicking on that section, a menu drops down with all the references.

## Ajustment to diferent sizes and browsers

To ensure that the page remains readable and usable independently of the size of the browser that the user is accessing, it was ensured that each item in the page was fit with some flexibility, this could be either an adaptation to sizes based on the parent, and by extention. the page itself, to the direct change of values of elements of the page when if becomes too small.
